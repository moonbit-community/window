## Description
Several white-box tests directly mutate `app_state_runtime.val.*` and internal arrays. These tests are useful, but the current test Interface is nearly as complex as the Implementation and will fight future deepening work.

## Design
Introduce test helper seams for runtime setup, deferred callback inspection, handler registration, and window fixture registration. Keep tests white-box where necessary, but stop encoding accidental field layout in every test.

## Acceptance Criteria
- [x] AppState tests use helper seams for common runtime setup and queue inspection.
- [x] View tests use reset/setup helpers instead of direct array mutation where possible.
- [x] The tests still verify behavior, not just helper behavior.
- [x] `moon fmt`, `moon info`, and `scripts/check_ci.sh` pass.
