## Description
`window_delegate.mbt` still keeps fullscreen transition state and maximized standard frame state in parallel arrays. `Window` also carries simple/exclusive fullscreen restore fields. This spreads fullscreen and restore semantics across several places.

## Design
Create a focused internal Module for fullscreen/maximized per-window state. Start by replacing parallel arrays for fullscreen transition and maximized standard frame with single-entry records. Only move simple/exclusive fullscreen restore fields if it improves locality without broad public API churn.

## Acceptance Criteria
- [x] Parallel arrays for maximized standard frame and fullscreen transition state are removed or hidden behind a single-entry state Module.
- [x] Close/cleanup paths clear the consolidated state through one seam.

- [x] `moon fmt`, `moon info`, and `scripts/check_ci.sh` pass.
